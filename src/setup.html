Phases

The practice round is not scored. Players see a notice before each round, and the kitchen is reset when a round starts. Set a duration to 0 to skip that round.

Cooks

Each cook is played by a person at the keyboard or by Claude. Set both to Claude to watch the model play itself, or disable the second cook for a solo kitchen.

Cook 1
Cook 2

Walk speed is in tiles per tick; cut speed is a multiplier (1 ≈ 3s per chop). Each cook can be tuned independently, and both cooks — human or Claude — are told their own speed and their teammate's.

Each cook's personality is independent — Claude cooks can be given completely different instructions, or none at all. Save named personality + schedule presets per cook so collaborators can load and compare them (like maps and rules prompts). Publishing copies the current text to the live player config.

The schedule field optionally changes that cook's personality mid-round: one or more @seconds lines, each followed by the new instructions text to switch to once that many seconds of the round have passed. Timing restarts at 0 at the start of every phase (so the same schedule replays fresh in the practice round and the scored round).

Agent rules prompt

Block 1 of the Claude prompt — game rules, cooperation guidance and reply format. This is cached and sent to every agent decision. Save named versions here so collaborators can load, edit and compare prompts. Publishing copies the current text to the live player config.

Claude agent

Block 2 (kitchen layout + per-cook personality) and block 3 (live state + action list) are built automatically each turn. Personality/instructions are set per cook above. Claude is asked for a decision each time its cook finishes an action, and it can only choose from actions that are actually possible — so it cannot make an invalid or pointless move.
